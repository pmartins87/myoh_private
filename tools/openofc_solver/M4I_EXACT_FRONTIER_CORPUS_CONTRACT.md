# M4I — resumable exact Fantasy-frontier teacher corpus

## Why this milestone exists

M4G measured a fresh exact F14 two-pass frontier at about 2.3255 s on a GitHub Ubuntu runner. M4H removes duplicated exact work with a one-pass frontier, but even a large constant-factor speedup does not make millions of fresh F14..F17 combinatorial solves an attractive inner-loop dependency.

The practical architecture is therefore hybrid:

1. keep an exact terminal oracle;
2. generate exact frontier labels offline, in parallel and resumably;
3. train a bounded terminal approximator on those labels;
4. validate it on disjoint exact held-out worlds;
5. retain exact fallback / error accounting outside the certified envelope.

M4I implements steps 1-2 and the lossless input contract for step 3. It does **not** promote an approximation yet.

## Corpus authority

Each row is generated by the M4H one-pass exact frontier and stores:

- deterministic world id and seed;
- Fantasy count F14/F15/F16/F17;
- the complete 24-suit-canonical terminal world key (Fantasy packet + completed normal board);
- exact best immediate HU points for the no-re-Fantasy branch if reachable;
- exact best immediate HU points for the re-Fantasy branch if reachable;
- explicit `oracle_only=true` provenance.

The current reachability sampler chooses normal-player actions uniformly from legal actions. This is deliberately labelled `UNIFORM_LEGAL_REACHABILITY_ONLY_NOT_POLICY`; it gives broad structural coverage but is not claimed to match the final equilibrium state distribution.

## Policy-information firewall

The terminal corpus is allowed to contain the hidden Fantasy packet because it belongs to the chance-world evaluator, not to the normal player's policy. M4I adds a separate 221-dimensional lossless terminal-world feature contract. It must never be reused as the normal-player information-set encoder.

The terminal feature layout is:

- bias: 1;
- Fantasy count F14..F17: 4;
- physical Fantasy packet membership: 54;
- completed normal Top/Middle/Bottom membership: 3 x 54.

Only one count coordinate, `N` packet cards and 13 board cards are active for a row.

## Ryzen scaling contract

`run_fantasy_frontier_shards.py` divides each Fantasy size into deterministic half-open world-id shards and executes shards across independent processes. Every shard has:

- exact parameter identity;
- canonical JSONL rows;
- SHA-256-bound manifest;
- atomic data/manifest replacement;
- deterministic resume that skips byte-identical completed shards;
- no dependence on process completion order.

The auditor rejects hash mismatch, range gaps/reorders, duplicate canonical worlds, bad provenance, impossible score bounds or empty branch labels. It can independently reconstruct selected canonical worlds and recompute their exact M4H labels.

## Next milestone

M4J trains the first terminal-frontier approximator from these exact rows and reports separate held-out errors for:

- branch reachability;
- no-re-Fantasy immediate score;
- re-Fantasy immediate score;
- final continuation-adjusted terminal utility over sampled continuation vectors.

No terminal approximator may enter strategic training until its error is quantified on exact worlds, and no live field test is promoted by M4I.
