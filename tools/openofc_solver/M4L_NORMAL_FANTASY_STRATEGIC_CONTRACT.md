# M4L — normal-vs-hidden-Fantasy strategic kernel + certified terminal boundary

## Scope

M4L closes the strategic plumbing gap for HU states with exactly one normal
player and one Fantasy player under the delayed-response timing contract already
used by M4E: the normal player completes all five placement rounds while the
Fantasy packet remains hidden, then terminal response is evaluated.

This milestone does **not** claim that the asymmetric policy is solved. It makes
the game/training boundary correct, resumable and safe enough to receive M4K
only after exact held-out certification.

## Information boundary

The policy input is `normal_fantasy_symmetry.canonical_node_view`.

It contains only:

- persistent normal/Fantasy identities and button;
- Fantasy **count** (14/15/16/17), which is public state;
- normal player's own board;
- normal player's remembered discards;
- current normal packet;
- round index.

The hidden Fantasy packet is absent. Suit canonicalization is selected only from
those visible fields. M4L adds a regression that changes the hidden Fantasy
packet while keeping every visible normal-player field identical and requires
the canonical policy key to remain byte-identical.

## Strategic learner

`NormalFantasyOutcomeSampling` is a one-strategic-player outcome-sampling
regret learner over chance worlds:

- all 232 opening actions;
- every legal place-2/discard-1 action on later rounds;
- no action abstraction;
- regret-matching+ by default;
- epsilon exploration;
- exact 24-way visible suit isomorphism;
- sampled hidden Fantasy packet and future normal cards;
- SHA-bound 50-state continuation vector;
- RNG state serialized in the checkpoint, giving byte-identical resume.

The optimized utility is the normal player's exact/approved terminal value for
the sampled world. Because the Fantasy player emits no public action before
normal completion under this timing contract, there is no opponent decision node
inside the five normal placement rounds.

## Exact default terminal authority

The default terminal evaluator is M4H one-pass exact search through
`OnePassExactFantasyFrontierCache`.

For a completed normal board it:

1. solves the best reachable no-re-Fantasy and re-Fantasy immediate branches;
2. adds the supplied persistent-player continuation vector exactly;
3. lets the Fantasy player choose the better branch;
4. returns the zero-sum negation to the normal player.

The independent older M4D two-pass frontier remains a parity oracle. The M4L
gate checks one deterministic F14 terminal world against that independent
implementation and checks exact cache reuse.

## M4K promotion firewall

M4L also defines `TerminalModelCertificate`. A learned terminal MLP cannot enter
this kernel merely because a smoke workflow completed.

The certificate is SHA-bound to:

- exact model bytes;
- exact held-out evidence bytes;
- allowed Fantasy sizes;
- allowed Joker counts;
- reachability confidence thresholds;
- certified continuation-delta interval;
- maximum held-out terminal-utility absolute error;
- held-out world count.

A certified MLP evaluator fails closed to M4H exact search when:

- the Fantasy/Joker stratum is outside the certificate;
- either branch reachability is uncertain;
- both branches are predicted unreachable;
- the relevant continuation delta is outside the certified interval;
- model SHA and certificate disagree.

No certificate is generated by this milestone. Freezing one requires Ryzen-scale
exact held-out evidence.

## Remaining strategic gaps

M4L makes `NORMAL_FANTASY_ASYMMETRIC` trainable. It does not yet close the full
50-state Bellman system. In particular, `FANTASY_FANTASY` states still require a
separate timing/information contract and strategic kernel before a complete
cross-hand relative-value solution can be certified.

That gap must be handled explicitly rather than silently treating two simultaneous
Fantasy players as independent exact arrangers.
