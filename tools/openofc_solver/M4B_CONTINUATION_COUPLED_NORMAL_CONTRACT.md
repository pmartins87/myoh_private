# M4B — continuation-coupled normal/normal strategic kernel

## Purpose

The original M4 current-hand MCCFR optimizes exact points in the present normal hand. That is a correct current-hand game, but it is not yet the intended long-horizon OFC objective because a normal-hand placement can change whether the next hand is normal, Fantasy 14/15/16/17, or a re-Fantasy state.

M4B removes the first architectural barrier: the full-action HU normal/normal solver can now optimize

`current_hand_points + V(next_HU_state)`

for an explicit 50-state continuation vector `V`.

No guessed Fantasy bonus is introduced. The next state is generated by the already exact `hu_continuation.py` / `fantasy_transition.py` rules.

## Exact invariants retained

- heads-up only;
- all 232 opening placements;
- all later legal place-2/discard-1 actions;
- exact 24-way suit isomorphism;
- exact terminal board evaluation and Joker semantics;
- full public action history in the information state;
- opponent packet/discards and future cards excluded from the information key;
- relative solver roles are mapped exactly to persistent player identities before continuation utility is applied;
- the supplied continuation vector contains all 50 HU meta-states and is SHA-256 bound into every checkpoint;
- deterministic PRNG state is checkpointed, so split/resume must reproduce the uninterrupted solver state exactly.

## Authority

M4B is `STRATEGIC_APPROX_HU_NORMAL_NORMAL_WITH_CONTINUATION`.

This milestone does **not** certify the continuation vector. A zero vector reproduces the earlier current-hand-only game exactly and exists only as a parity baseline. A nonzero vector changes the strategic objective and is accepted only as explicit input.

`STRATEGIC_CERTIFIED` remains forbidden until a best-response/exploitability gate passes. `ALL_VARIABLE_CERTIFIED` additionally requires the asymmetric normal/Fantasy and Fantasy/Fantasy one-hand kernels, outer fixed-point/average-reward convergence, any relevant table-fund cap, and bounded production-policy loss.

## Files

- `strategic_continuation_cfr.py`: continuation-coupled suit-canonical MCCFR.
- `strategic_continuation_runner.py`: deterministic resumable runner and 50-state value-file format.
- `test_strategic_continuation_cfr.py`: Bellman utility, identity mapping, objective binding and one-iteration tests.
- `test_strategic_continuation_runner.py`: exact split/resume test.

## Next strategic gates before field testing

1. Build the normal-vs-Fantasy one-hand kernel using the exact Fantasy response/search machinery and verified KKPoker timing semantics.
2. Build the both-Fantasy kernel.
3. Assemble all 25 player-exchange canonical meta-states into a Bellman/relative-value iteration driver and solve the continuation vector rather than supplying it externally.
4. Run Ryzen-scale multi-seed training for the solved objective.
5. Implement held-out best-response/exploitability certification.
6. Distill/export the certified policy to production and measure policy loss against the training/search oracle.

Only after those gates pass should the next field test be used to evaluate the intended normal-game AI rather than another temporary baseline.
